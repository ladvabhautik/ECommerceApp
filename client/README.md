# IBL Ecommerce React Frontend Setup

## Prerequisites
- Node.js and npm installed

## Installation Steps

1. **Download the project**  
   Extract the attached ZIP file.

2. **Navigate to Client Folder**
   ```bash
   cd client
   ```

3. **Install Node Modules**
   ```bash
   npm install
   ```

4. **Run the Frontend**
   ```bash
   npm run dev
   ```

5. **Your frontend will be running (usually on http://localhost:5173 or as displayed in terminal)**

---

If any issue occurs, make sure dependencies are installed correctly or delete `node_modules` and reinstall.
